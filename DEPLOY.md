# Tier 1 — Deployment Guide

## Step 1: Set up your environment

```bash
cd wine-quality-app
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Step 2: Copy your data

Copy your existing CSV files into the `data/` folder:

```
data/
  winequality-red.csv
  winequality-white.csv
```

These are the same files from your original project.

## Step 3: Train the model

```bash
python train.py
```

This will:
- Load and clean both red and white wine datasets
- Run GridSearchCV (takes ~1 min)
- Save `model/pipeline.pkl`
- Print accuracy + F0.5 score

## Step 4: Run locally

```bash
streamlit run app.py
```

Open `http://localhost:8501` in your browser.

---

## Step 5: Deploy to Hugging Face Spaces (free, permanent URL)

### 5a. Create an account at huggingface.co

### 5b. Create a new Space
1. Go to https://huggingface.co/new-space
2. Space name: `winescore` (or anything you like)
3. SDK: **Streamlit**
4. Visibility: Public
5. Click **Create Space**

### 5c. Push your code

```bash
# In your wine-quality-app folder
git init
git add .
git commit -m "Initial WineScore app"

# Add the HuggingFace remote (replace YOUR_USERNAME)
git remote add hf https://huggingface.co/spaces/YOUR_USERNAME/winescore
git push hf main
```

HuggingFace will automatically build and deploy. Your app will be live at:
`https://huggingface.co/spaces/YOUR_USERNAME/winescore`

> **Note**: The `model/pipeline.pkl` file must be committed and pushed. 
> Git LFS is not needed since it should be under 100MB.
> If it exceeds 100MB, run: `git lfs track "*.pkl"` before committing.
